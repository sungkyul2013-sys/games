# 🌅 Sunset Runner (선셋 러너)

석양을 배경으로 끝없이 질주하는 **Subway Surfers 스타일 3D 엔드리스 러너** 게임입니다.
Three.js로 만든 단일 HTML 파일이며, 별도 설치 없이 브라우저에서 바로 즐길 수 있습니다.

## ▶ 실행 방법

가장 간단한 방법은 `index.html`을 더블클릭해 브라우저에서 여는 것입니다.

> 3D 엔진(Three.js)은 인터넷(CDN)에서 불러오므로 **첫 실행 시 인터넷 연결이 필요**합니다.

로컬 서버로 실행하려면:

```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 🎮 조작법

| 동작 | 키보드 | 모바일 |
|------|--------|--------|
| 좌/우 이동 | ← → 또는 A / D | 좌/우 스와이프 |
| 점프 | ↑ 또는 W | 위로 스와이프 / 탭 |
| 슬라이드 | ↓ 또는 S | 아래로 스와이프 |
| 일시정지 | P 또는 ESC | ⏸ 버튼 |

## ✨ 주요 기능

- **3개 레인** 무한 러너, 시간이 지날수록 빨라지는 속도
- **장애물** 3종: 기차(피하기), 낮은 바리어(점프), 높은 바리어(슬라이드)
- **코인 수집** 및 점프 호(arc) 위 보너스 코인 배치
- **파워업 4종**
  - 🧲 자석: 코인 자동 수집
  - 🚀 점프부츠: 슈퍼 점프
  - ✨ x2: 점수 2배
  - 🛹 호버보드: 충돌 1회 방어
- **최고 기록 저장** (localStorage)
- WebAudio로 합성한 효과음 (외부 음원 파일 없음)
- 글래스모피즘 UI와 석양 그라데이션의 감성적 디자인

## 🛠 기술

- 단일 `index.html` (HTML + CSS + JavaScript)
- [Three.js](https://threejs.org/) r160 (CDN, ES module importmap)
- 외부 에셋 의존성 0 — 모든 지오메트리·머티리얼·사운드를 코드로 생성
